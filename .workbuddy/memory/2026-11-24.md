## 根因（下载/启动「巨大问题」的真正原因）
1. **库路径只按 maven 坐标拼，忽略 `downloads.artifact.path`**。带 classifier 的库（`org.lwjgl:lwjgl:3.3.3:natives-windows`）
   被解成 `lwjgl-3.3.3.jar` → natives jar 写进主 jar 位置，覆盖主 jar；1.19+ 的 natives 库也永远进不了 classpath
   → `UnsatisfiedLinkError` / `NoClassDefFoundError`。**这是必崩根因**。
2. `natives` 里的 `${arch}` 未替换 → 下载 `natives-windows-${arch}.jar` 必 404 → 整个安装中断。
3. classpath 把 natives 库也算进去、且「文件存在就加」掩盖缺失。
4. 完整性检查一旦有缺失就**拒绝启动**。
5. 空参数被命令行吞掉（`--clientId "" --xuid`）→ jopt-simple 参数错位；`@argfile` 在 Java 8 上不支持。
6. 下载源里有已下线的 MCBBS 镜像。

### 正版登录用不了的根因（已实测复现）
- 旧代码：`POST login.microsoftonline.com/consumers/oauth2/v2.0/devicecode` + `client_id=00000000402b5328`
  → **AADSTS700016 Application with identifier ... was not found**（该端点只认 Azure AD 注册应用）。
- 正确做法（实测通过）：MSA 自己的设备码端点
  - `POST https://login.live.com/oauth20_connect.srf`
    body: `client_id=00000000402b5328&scope=service::user.auth.xboxlive.com::MBI_SSL&response_type=device_code`
  - `POST https://login.live.com/oauth20_token.srf`
    body: `client_id=..&device_code=..&grant_type=urn:ietf:params:oauth:grant-type:device_code`
  - 实测返回 user_code / verification_uri=https://www.microsoft.com/link / interval=5 / expires_in=900；
    轮询返回 `authorization_pending`。
- 限制：该应用不能叠加 `wl.offline_access`（invalid_scope），**拿不到 refresh_token**，约 24h 需重登。
  已在设置里加可选 `msClientId`（Azure 公共客户端 ID），填了走 consumers v2.0 + offline_access 才有续期。
- 登录 UI 改为 HMCL 式一键：后台取设备码 → 自动开浏览器 → 后台每 5s 轮询 → 成功/失败事件回 UI。

## 第五轮（21:10-21:20）：1.21.11 启动崩溃（quickPlay）
- 用户日志 `D:\minecaft\cs\logs\yxg-launcher.log`：游戏**已启动到 Main.main**（说明 classpath/natives/库全对），
  崩在 `IllegalArgumentException: Only one quick play option can be specified`（Argument parsing）。
- 根因：1.20.2+ 的 version JSON 用 **`rules[].features`** 门控参数：
  `--demo`(is_demo_user) / `--width,--height`(has_custom_resolution) / `--quickPlayPath`(has_quick_plays_support) /
  `--quickPlaySingleplayer|Multiplayer|Realms`(is_quick_play_*)。我们只判 os 规则，`features` 全忽略 →
  3 个 quickPlay 同时进命令行。
- 修法：`LibRule` 加 `features` map；`parseRules` 解析；新增 `featureEnabled()` + `ruleMatches()`
  （has_custom_resolution=true，其余 false），`Library::appliesTo` 与 `parseArgList` 都走 `ruleMatches`；
  再加一层兜底：命令行里出现多个 `--quickPlay*` 时只保留第一个；补 `${quickPlay*}` 占位符替换。
- 另注：日志里 `restricted method` / `Unsupported JNI version` 是 Java 25 + LWJGL 3.3.3 的正常告警；
  1.21.11 官方要 Java 21，用户机器上是 JetBrains 25（能用，个别 mod 可能不兼容）。
- 部署：1,641,984 字节（light 已关闭，直接覆盖）。

    180s 超时但进程活着 → `GameStart` + 提示可能还在加载。
  - 然后才等进程退出 → `GameExit`；UI 里若 `wasLaunching` 则不再重复弹「异常退出」。
  - `StartLaunch` 里 `m_launching` 期间重复点击直接提示「正在启动中」。
