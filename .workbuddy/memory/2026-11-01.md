## MCLauncher：背景→主题色联动（HMCL MonetFX 机制，14:19）

用户确认实现「背景提取主题色」——选壁纸时界面主色自动跟随变化。

### HMCL 源码核实
- `BuiltinBackground.java`：3 张内置壁纸各绑定一个预计算 MonetFX seed 色——2021-08-26→`#3F6AA2` 蓝、2016-02-25→`#354264` 深蓝、2015-06-22→`#FBC578` 暖黄；默认 FALLBACK=2021-08-26。
- `WallpaperColorExtractor.java`：自定义壁纸用 `ColorScheme.extractColor(image)` 提取主色作为 seed。
- `ThemeColor.java`：`STANDARD_COLORS` 默认 blue=`#5C6BC0`；seed 经 MonetFX `ColorScheme` 生成完整 Material You 调色板应用到 UI。

### 实现（C++ 简化版 MonetFX）
- `Theme.h`：`ACCENT/ACCENT_DK/ACCENT_CONT/GREEN/GREEN_DK/ORANGE` 从 `constexpr` 改为 `extern COLORREF`（运行时可变）；中性 surface 色（BG/CARD/CARD2/TEXT/MUTED/LINE/LINE_SOFT/RED）保持 constexpr。新增 `SetSeed(COLORREF)` / `ResetSeed()` / `BuiltinSeed(int)`。
- `Theme.cpp`：HSL 调色板生成——RGB↔HSL 转换；SetSeed 从 seed 派生 primary(明度钳 0.30~0.46 保证白字可读)/primary-container(明度 0.90 配深字)/tertiary(色相+40°)；同 seed 缓存避免重复计算。BuiltinSeed 映射 3 张壁纸的 #3F6AA2/#354264/#FBC578。
- `Background.cpp`：`extractSeedFromImage()`（GDI+ 缩到 1x1 取平均色，带路径缓存，对齐 WallpaperColorExtractor）+ `CurrentThemeSeed()`（Builtin→BuiltinSeed；Image/Cycle→提取；Solid→0）。`Paint()` 开头同步 `SetSeed(seed)` 或 `ResetSeed()`。

## MCLauncher：修复下载失败"卡死" + 下载进度弹窗（15:02）

用户反馈：下载 NeoForge 1.21.11 时「一个安装失败，全部卡死」，报 `open file failed`（jracy natives 库）；并要求下载按钮文字改、下载时弹 HMCL 式进度窗口。

### 根因
- 「卡死」：`OnTimerTick` 的 `InstallError` 分支只复位 `m_installing`/`m_progressText`，**没复位 `m_progress`**，进度条卡在失败位置不动，看起来像卡死。
- `open file failed`：用户游戏目录在 **U 盘**（`U:\minecraft\s`），是本地写入失败（空间不足/只读/断开）。`Http.cpp Download` 里 `create_directories` 的 `ec` 被忽略、`ofstream` 失败也只报笼统的 "open file failed"，无法定位。已改进错误报告。

### 修复
- `Ui.cpp InstallError`：加 `m_progress = 0.0f` 复位进度条。
- `Http.cpp Download`：`create_directories` 失败报 `create dir failed: <message>`；`ofstream` 失败报 `open file failed (errno N, winerr N)`；加 `<cerrno>`。
- 下载按钮文字：「⬇ 下载安装」→「⬇ 下载」。
- **下载进度弹窗**（HMCL 式）：`Ui` 加 `m_showDlDialog/m_dlDialogTitle` + `DrawDownloadDialog`；点「下载」时弹出居中卡片（遮罩+标题+进度条+状态文字+关闭/取消按钮），`InstallDone/InstallError` 更新结果；`OnLButtonDown` 弹窗显示时吞掉其余点击，点「取消」调 `abortInstall()`。进度条颜色：下载中蓝、失败红、完成绿。

## MCLauncher：修复 manifest 单源 DNS 失败（WinHTTP 12007，15:08）

用户截图：`安装失败: 网络错误: send failed (WinHTTP 12007)`，且「可下载版本」列表空白。

### 根因
- **WinHTTP 12007 = ERROR_INTERNET_NAME_NOT_RESOLVED（DNS 解析失败）**，是网络环境问题（当前下载源域名解析失败/网络波动）。
- 但代码缺陷：`fetchManifest` 只尝试**单一源** `manifestUrl(s)`，无多源回退（文件下载 `candidateUrls` 有回退，manifest 却没有）。源域名 DNS 失败 → 直接报错 → 版本列表空白（manifest 没加载）。

### 修复
- `fetchManifest` 改为多源回退（HMCL 式）：当前源 → BMCLAPI → MCBBS → Mojang，任一成功即返回；抽 `tryOnce` lambda 复用解析+排序逻辑。

### 部署
- DLL(1,228,288) 编译成功，已部署 Cache\gui\dll\（light 运行中，用 NTFS 改名释放）。重启 light 生效。若所有源都 DNS 失败，说明是网络断开/DNS 全局故障，需用户检查网络。
