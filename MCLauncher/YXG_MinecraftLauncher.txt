我的世界启动器（HMCL 风格 + 多实例管理）

用现代 C++20 编写、纯 GDI+ 自绘原生窗口（无 JS）的 Minecraft 第三方启动器，编译为 light 的
附属插件 DLL（Cache\gui\dll\），在 light 侧边栏注册一个原生面板。

主要功能：
- 实例模型：一个文件夹可放多个游戏，可添加任意多个文件夹；「版本选择」里选择 / 卸载 / 连文件删除
- 版本管理（点侧边栏「版本管理」即进入当前版本的管理）：
  · 模组：HMCL 式卡片 + 模组封面，右下角开关启用/停用，检测并补充前置
  · 加载器：Fabric / Quilt / Forge / NeoForge 带 logo 卡片，安装 / 更新 / 卸载
  · 版本设置：Java、内存、分辨率、全屏、版本隔离、完整性检查、昵称、直连服务器、JVM/游戏参数
  · 资源包：pack.png 封面 + 开关（改写 options.txt）
  · 世界：存档 icon.png 封面、备份、删除
  · 原理图：.schematic / .litematic / .schem / .nbt 管理
- 下载：游戏（正式版/测试版/快照版/愚人节/远古版，按发布时间倒序，可改游戏名）、
  模组 / 资源包 / 光影（Modrinth 卡片 + 封面 + 中英双语检索）、
  世界（对接 CurseForge：封面 + 一键下载安装；也支持本地管理与 zip 导入）
- 启动时检查游戏完整性，缺失可自动修复（全局 / 单局可分别开关）
- 数据全部在「主程序目录\Data\mlc」下（config / games / cache / backups / logs 细分）
- 账号：可保存多个账号并选择使用（记住当前账号，下次启动直接进入）；离线登录（精确离线 UUID）
  与微软正版登录（设备码，自动打开授权页，保存 refresh_token，令牌过期自动续期）
- 背景设置（纯色 / 内置壁纸 / 自定义图片 / 目录轮播 + 磨砂）

安装：把 YXG_MinecraftLauncher.dll 放进 light.exe 同级的 Cache\gui\dll\ 目录，重启 light，
侧边栏出现「我的世界启动器」即可。覆盖旧版本前请先备份旧 DLL。
